# PWA 图标说明

为了完整支持 PWA 功能，需要在此目录添加以下图标文件：

## 必需图标

1. **icon-192x192.png**
   - 尺寸：192x192 像素
   - 用途：Android 主屏幕图标、应用列表

2. **icon-512x512.png**
   - 尺寸：512x512 像素
   - 用途：Android 启动画面、高分辨率设备

3. **favicon.ico**
   - 尺寸：16x16, 32x32, 48x48
   - 用途：浏览器标签页图标

## 图标设计建议

- 使用简洁的羽毛球或场地相关图标
- 背景色建议使用 #1a1a1a（深色）或 #f59e0b（琥珀色）
- 图标内容居中，留有适当边距
- 确保在小尺寸下也清晰可辨

## 快速生成图标

你可以使用以下在线工具生成 PWA 图标：
- https://www.pwabuilder.com/imageGenerator
- https://realfavicongenerator.net/
